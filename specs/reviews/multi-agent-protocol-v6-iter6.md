# Контекст

6/6 фіксів iter5 підтверджено як приземлені й ефективні (зокрема `-B` — рев'юер
відтворив, що без нього diff падає на кінцевому порожньому рядку; повний refspec у
`--single-branch` клоні оновлює `origin/main` і приносить `task/*`; поле перед `---`
не ламає G7; guard на сусідній клон спрацьовує без видалення чужого). 4 нових знахідки.

# Що підтверджено як коректне (iter6)

Гонка claim (дослівно), ранній абор + очистка (з кореня і зсередини worktree) + повторний
claim; §5.5 у тому самому клоні з пробілом і autocrlf=true, у свіжому звичайному клоні,
після RECLAIM → СТОП; §5.6; §6.0: дві `small/*` від однієї бази — G7-lite з rebase
інтегрує обидві, без rebase друга не ff; G7 diff: (i) сусідня секція + власні тіки +
`NOTE=` перед `---` → rc=0, (ii) власний текст змінено → rc=1; уся внутрішня
консистентність §2/§6/§8/§9/§10/§12; §14 13/13; проєктна незалежність.

# Залишкова невизначеність

- Локальні bare-репо, Git for Windows 2.52; хостинги не перевірялись.
- CRLF-шлях проходить частково завдяки MSYS2 sed, що зрізає CR; тепер закрито
  `[[:space:]]`, але POSIX sed на справжньому CRLF-checkout наживо не перевірено.
